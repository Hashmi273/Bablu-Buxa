# Bablu Buxa Real Estate

Official luxury real estate web application for **Bablu Buxa Real Estate**.

## 🌟 Features
- **Modern Luxury Branding**: 40% White, 40% Royal Blue (#0B2545), and 20% Metallic Gold (#C69214).
- **Home Page**: Curated inventory of luxury villas, modern apartments, commercial suites, and gated plots.
- **Interactive Loan EMI Calculator**: Real-time principal, tenure, interest rate, and monthly payment calculator.
- **Contact Us & VIP Tour Booking**: Interactive inquiry form with direct WhatsApp integration.
- **Terms & Conditions**: Complete legal terms, RERA compliance disclaimer, and site visit policy.
- **Privacy Policy**: 100% data confidentiality and zero-spam guarantee.

## 🚀 Getting Started

### Run locally:
```bash
node server.js
```
Then open: [http://localhost:3000](http://localhost:3000)

## 📄 Pages
- `index.html` - Home Page
- `contact.html` - Contact Us Page
- `terms.html` - Terms & Conditions
- `privacy.html` - Privacy Policy
- `styles.css` - Custom Theme & Luxury Styling
- `app.js` - Dynamic Filters, Modals & EMI Calculator
